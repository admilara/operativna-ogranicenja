# data/

Ovdje se lokalno spremaju mrežni modeli (`.raw`), smjernice i rezultati.

**Sadržaj ove mape se ne objavljuje** — `.gitignore` isključuje sve osim ove datoteke.
Modeli HOPS-a i popisi korisnika u postupku priključenja nisu javni podaci.

Predložena struktura:

```
data/
  modeli/        ScA_2029.raw, ScB_2029.raw, ... (42 modela, scenarij × godina)
  podloge/       smjernice, studijski zadatak, prilozi
  rezultati/     izlazi proračuna
```
